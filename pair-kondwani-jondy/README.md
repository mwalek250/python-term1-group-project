------------------------------------------------------------
PROJECT 3 — WORD COUNTER
------------------------------------------------------------

Description:
This program accepts a sentence from the user and analyzes it.

The program displays:
- Number of words
- Number of characters (excluding spaces)
- Longest word in the sentence

Features:
- Uses functions
- Includes input validation
- Clean and readable output
- Proper code structure with comments

How to Run:

1. Open Termux
2. Navigate to the project folder:

   cd python-term1-group-project/pair-kondwani-jondy

3. Run the program:

   python question3.py

Example:

Input:
Enter a sentence: Python programming is powerful

Output:
Number of words: 4
Number of characters (no spaces): 27
Longest word: programming
